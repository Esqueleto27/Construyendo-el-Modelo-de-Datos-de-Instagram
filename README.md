# InstaSchema – Instagram Database Design

## Project Overview

This project focuses on designing a **relational database model inspired by Instagram**, using Python and SQLAlchemy. The goal is to define entities, relationships, and constraints that represent how a social media platform stores and organizes data.

The database structure is visualized through a **UML (Entity-Relationship) diagram**, providing a clear overview of the system architecture.

---

## Project Idea

The objective of this project is to model the backend structure of a social media platform similar to Instagram.

The system includes core entities such as users, posts, comments, and relationships between them. This project emphasizes **data modeling, database relationships, and backend architecture design**.

---

## Technologies Used

- **Python**
- **SQLAlchemy**
- **UML (Entity-Relationship Diagram)**
- **QuickDatabaseDiagrams**

---

## Database Design

The database includes multiple entities representing a social media platform, such as:

- Users
- Posts
- Comments
- Likes
- Followers / Following relationships

Each entity is defined with its attributes and relationships to simulate real-world application behavior.

---

## UML Diagram

The project generates a visual representation of the database structure:

- Tables and their attributes
- Relationships between entities
- Foreign keys and constraints

The diagram helps understand how data flows within the system.

---

## How It Works

1. The database models are defined using SQLAlchemy.
2. Each class represents a table in the database.
3. Relationships between entities are established using foreign keys.
4. A UML diagram is generated to visualize the structure.
